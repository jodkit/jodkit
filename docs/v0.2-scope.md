# JodKit v0.2 scope

**Purpose:** Bound v0.2 implementation slices. Default **no** until listed IN or agreed in a PR.

**Baseline:** [v0.1-scope.md](v0.1-scope.md) remains done in [apps/playground](../apps/playground/) and `packages/*`.

## Slice 1 (complete)

```text
Request auth context (subject from header / dev token stub)
Subject-aware PermissionChecker (kernel.can uses request subject)
users collection (defineCollection -> PostgreSQL -> REST -> OpenAPI -> MCP)
Generalized collection REST/MCP (not products-only)
GET /admin/collections (metadata index, permission-gated)
Tests for auth subject, users CRUD, admin route
```

## Slice 2 (complete)

```text
pages collection (CMS proof: slug, title, body, status, optional published_at)
Field types toward v0.2 target: money (numeric), optional enum on string/text
Validation for enum + money; same pipeline as products/users
Migration 003_jodkit_pages.sql, PostgresPageStore, pages module, REST/OpenAPI/MCP
Playground integration tests (pages CRUD, enum 400, admin + OpenAPI)
Eight documented scalar types: uuid, string, text, number, money, boolean, datetime, json
```

## IN (v0.2 slice 3)

```text
apps/admin: Vite + React metadata-driven shell (collections list, record table, create form)
Dev proxy to playground; x-jodkit-subject header; admin metadata includes enum (+ relationTo later)
GET /admin/collections field payload extended for admin forms
relation field type + relationTo; posts collection (page_id -> pages)
Migration 004_jodkit_posts.sql, PostgresPostStore, posts module, tests
Admin relation widget: select from GET /api/{relationTo}
Nine types in docs: prior eight + relation (media still OUT)
```

## OUT (slice 3)

```text
Next.js admin adapter, login UI, RBAC editor
shadcn/TanStack polish as requirement (plain markup OK)
Plugin/module admin screens, media picker, rich text
Production CORS/deploy story
Bi-directional relations, many-to-many, cascade delete product
GraphQL, commerce
Kernel collection registry / onInstall
Passwords, sessions, OAuth, JWT product
Plugin sandbox
CLI
```
