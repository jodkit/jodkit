# Vision

JodKit is an **open-source, AI-native, modular full-stack web application platform** aimed at becoming a modern alternative to WordPress - not merely another CMS.

## What you can build

Websites, blogs, corporate sites, ecommerce, portals, memberships, SaaS, booking systems, custom business apps, API-first apps, and AI-powered experiences - with the same extensibility philosophy WordPress popularized, but on a modern TypeScript/Node.js foundation designed for AI-assisted development.

## Core positioning

> A WordPress-like platform built for the modern web and designed from the beginning for AI-assisted development.

> An open-source, AI-native, modular full-stack web application platform for building websites, ecommerce, portals, SaaS applications and custom web applications.

## Why now

WordPress succeeded by combining CMS, themes, plugins, hooks, admin, and ecosystem scale. Modern Node stacks often excel at one slice (headless CMS, ecommerce engine, framework) but rarely unify CMS + themes + plugins + optional commerce + AI-readable architecture in one coherent model. JodKit targets that gap.

## Differentiation (intended)

Not "WordPress in Node.js" alone. The combination we are designing for:

- WordPress-style ecosystem philosophy
- Modern TypeScript architecture
- True modularity (install/run only what you need)
- Provider abstraction (no hard-coded vendors in core)
- Modern APIs and MCP
- AI-native project structure and workflows
- Developer-first extensibility
- Practical deployment (single VPS first)

## What we are not building

- Only a CMS, only ecommerce, or only a website builder
- Only a backend framework or only an AI coding assistant
- A monolith where every site runs every subsystem
- Unrelated packages without a shared platform contract

## Product definition (current)

> An open-source, modular, AI-native full-stack web application platform that combines CMS, themes, plugins, APIs, ecommerce and application development under a unified extensible architecture.

Developers should be able to start with a minimal CMS and add capabilities progressively.
