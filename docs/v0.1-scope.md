# JodKit v0.1 scope

**Purpose:** Prevent scope explosion during spikes and walking skeleton. If a feature is not listed IN, default answer is **no** until v0.2+.

**Implementation status (2026-10-07):** v0.1 IN items are implemented in [apps/playground](../apps/playground/) and `packages/*` (run `pnpm test:playground`). CLI and full auth product remain deferred as noted below.

**Implementation detail:** [implementation-guide.md](implementation-guide.md) | **Agents:** [AGENTS.md](../AGENTS.md)

## IN (v0.1)

```text
Kernel (minimal)
Fastify HTTP server
PostgreSQL
Drizzle (behind Data Layer)
Module system (install/enable/disable hooks)
Plugin foundation (manifest + registration)
Capability registry
Provider contracts (resolve at runtime)
Schema collections (defineCollection)
Field metadata + validation rules (minimal set)
REST API (generated)
OpenAPI (generated)
MCP tools (generated from same metadata)
Basic permissions (check hooks - not full RBAC UI)
Events (register + emit at least one)
Tests (unit + at least one integration path)
Migrations (core + module/plugin via registry)
CLI only if required by walking skeleton (otherwise defer)
```

## OUT (v0.1)

```text
GraphQL
Commerce (cart, checkout, orders, payments module)
Themes and theme rendering
Multi-site management tooling
Marketplace
Plugin sandbox / process isolation
Visual page builder
Advanced metadata-driven admin UI
External search engines (Meilisearch, Elasticsearch, ...)
Billing and subscriptions
AI coding agent / AI doctor CLI
Full audit log product
i18n CMS product (Unicode content may exist; i18n system deferred)
Auth product (basic hooks OK; full auth module deferred to v0.2 per roadmap)
```

## Boundary notes

| Topic | v0.1 |
|-------|------|
| `products` collection | IN as **walking skeleton proof**, not commerce module |
| Admin UI | OUT (API-only clients and tests) |
| Queue workers | OUT (interface stub OK in contracts only) |
| Redis | OUT |
| Next.js playground app | OPTIONAL; Fastify-only app is enough |

## When scope changes

Update this file and [implementation-guide.md](implementation-guide.md) in the same PR. Do not expand v0.1 without explicit agreement.
